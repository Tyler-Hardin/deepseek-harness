# Agent Note: 移动端侧边栏抽屉——滑动手势与选中后自动收起

Status: implemented

[English](2026-08-25-mobile-sidebar-drawer.md) | 中文

> 适用范围：侧边栏壳在窄视口下的行为——列不再挤压对话区而是成为覆盖式抽屉、触摸手势如何开合、选中条目后如何自动收起。其所在的组合模型（插槽、store、owner 份额）见 [slot 体系标准](../architecture/2026-07-22-slot-type-chain-implementation.zh.md)；所属客户端插件树见 [Web 客户端架构说明](../architecture/2026-07-19-gui-web-client-architecture.zh.md)。

## Problem

在窄视口（移动浏览器与 Android 壳，低于 `SIDEBAR_AUTO_COLLAPSE` 断点）下，侧边栏自动收起为 56px 窄条，但展开时是挤压对话区而非露出它：三列让步链保持侧边栏轨道为偏好宽度，由中栏吸收差额——375px 手机上对话区只剩约 95px。没有任何触摸手势——打开只能点窄条上的切换钮——而且选中工作区或会话后抽屉仍盖在刚跳转过去的对话之上。恰好在 Android 壳所面向的界面上，侧边栏成了最笨拙的部分。

## Decision

断点以下，侧边栏变为覆盖对话区的抽屉：

- **列脱离网格。** 窄视口下框架首轨道为 `0px`，侧边栏列以 `position: absolute` 锚定在左缘；其宽度在 56px 窄条与展开偏好值之间过渡，并封顶为 `viewport - 56`，保证至少留有窄条宽度的遮罩可见。中栏保持整宽，并在两种窄状态下都带固定的 `padding-left: 56px`，因此抽屉打开时对话区的内容盒始终不变——抽屉只是盖住同一内容盒更宽的一段，文本行不会重排（AppFrame.module.css）。由于绝对定位的侧边栏脱离网格流，仍在流内的两列显式声明 `grid-column`（中栏 `2`、详情栏 `3`）——否则它们会自动左移一格，详情面板会占满整个中栏。
- **点击遮罩即收起。** 抽屉打开期间，抽屉下方覆盖一层 `--dsw-alias-bg-mask-2` 遮罩；触摸它即关闭抽屉。
- **滑动手势。** 从左侧窄条内起手的右滑打开抽屉；在打开的抽屉上起手的左滑关闭它。列的 `touch-action: pan-y` 把水平移动交给框架的 pointer 处理器，同时竖直滑动仍滚动内嵌的会话列表——且该锁定只在列上而非整个框架，因此对话区自身的横向滚动（代码块）不受影响。鼠标拖动不算滑动；窄条切换钮的点击照常工作。
- **选中后自动收起。** 打开会话、新建会话、派生会话都会收起抽屉。框架通过侧边栏 owner 份额下发 `closeSidebar` 回调；它在窄视口关闭抽屉，在宽视口为空操作，因此桌面端常驻列不会因选中而消失。`SidebarRoot` 把回调转发给工作区浏览区（`sidebar.workspaces` owner 份额），并在自己的"新建会话"控件里也调用它。

状态：布局 store 新增 `closeSidebar` action（窄：清 `narrowExpanded` 覆盖；宽：偏好宽度置 0）。它是显式关闭——区别于 `toggleSidebar`，后者会把已收起的抽屉重新打开。

## Consequences

- 56px 窄条仍是窄视口的收起态，因此切换 / 新建会话 / 搜索 / 添加工位 / 设置这些入口无需新的顶栏即可触达。抽屉打开期间盖住窄条；抽屉右上角的面板切换钮、遮罩、左滑都可关闭。
- 跨越断点时侧边栏在网格内（宽）与绝对定位（窄）之间是瞬切而非动画过渡；该点状态本身也会自动收起，因此瞬切是预期行为而非卡顿。
- 窄视口下隐藏侧边栏拖拽手柄：抽屉宽度固定（偏好值封顶），与移动端抽屉惯例一致。
- ui-layout 的客户端测试通道豁免（vitest.config.ts 中的 `TODO(gui)` 清单）覆盖 AppFrame 及其 owner 契约；ui-sidebar 壳与布局 store 仍保持逐文件 100%。

## Alternatives considered

| 已否决 | 一句话理由 |
|---|---|
| 挤压式：侧边栏留在网格内，中栏吸收差额 | 375px 手机上对话区只剩约 95px——这正是要修的笨拙，而非可用的抽屉 |
| 完全隐藏窄条，另做移动端顶栏汉堡按钮 | 等于重做对话区头部；窄条已承载全部入口，且无触摸手势时切换钮仍是兜底 |
| 平移整宽离屏面板，以裁窗方式露出窄条 | 窄条与宽内容本是同一元素（SidebarRoot 在两种布局间交叉淡化），只有对被裁列的宽度过渡能在左缘保持窄条可见 |
| 全框架 `touch-action: pan-y` 滑动检测 | 会在触摸设备上禁用对话区代码块的横向滚动——平移锁定必须只落在侧边栏列上 |
